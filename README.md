# Allsight × The Maslow — Proposal Deck

18-slide proposal deck for The Maslow Sandton and The Maslow Time Square.

| File | What it is |
|---|---|
| `index.html` | The deck source — plain HTML slides, editable. Open in a browser. |
| `deck-stage.js` | Presentation player: ←/→ to navigate, thumbnail rail, print to PDF. |
| `assets/` | Images and fonts used by the slides. |
| `Allsight Maslow Proposal (full).html` | Single self-contained file (everything inlined) for sharing. |
| `Allsight Maslow Proposal.html` | Original bundled export. |
